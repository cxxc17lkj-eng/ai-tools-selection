ChatGPT Plus / Pro 代充安全核对清单

购买前

  • 确认商品是 Plus、Pro 5x、Pro 10x 还是 Pro 25x。
  • 查看 OpenAI 官方定价页和本人账号当前可用方案。
  • 确认实时价格、账号要求、交付方式和处理时间。
  • 问清新开、续费、升级和原订阅未到期分别如何处理。
  • 保存商品说明、付款记录和异常处理规则。

办理过程中

  • 不把密码、验证码、恢复码、Cookie 或 API Key 当作普通客服资料发送。
  • 本人需要登录时，优先在自己的设备和浏览器内完成。
  • 不安装来源不明的软件、浏览器扩展或远程控制工具。
  • 不在陌生网页复用邮箱密码。
  • 不把私人聊天、工作文件或公司秘密交给共享账号。

完成后

  • 在本人 ChatGPT 官方页面核对套餐名称和有效期。
  • 检查是否出现陌生登录、陌生设备或安全提醒。
  • 若曾临时授权第三方操作，及时修改密码并检查双重验证设置。
  • 保存订单和付款凭证，直到服务周期及异常处理结束。

高风险信号

  • 只强调低价，不说明最终开通到哪个账号。
  • 要求发送邮箱密码、短信验证码或恢复码，却不能解释必要性。
  • 要求提供浏览器 Cookie、API Key 或远程控制权限。
  • 不提供订单或付款记录。
  • 用其他用户截图代替本人账号验收。
  • 对退款、重复付款和账号不符合条件完全没有说明。

官方核对

  • ChatGPT 定价
  • OpenAI 账号共享政策
  • ChatGPT 支持的国家和地区
